# 早期美式电视卡通风格

## 风格定位与参考依据

目标是 **early American hand-drawn television animation / traditional cel animation with simplified painted background**：以有限制作预算换取清楚人物表演，用深色赛璐珞可动层叠加少线、浅线、大综合色块的固定绘景。背景只交代动作所需空间，不承担沉浸式世界展示；背景信息不足是主动简化，不是缺陷。

- [`reference-03-natural-shape-simplification-v5.jpg`](../assets/reference-03-natural-shape-simplification-v5.jpg)：植物团块、开放边缘、自然空间简化，以及场景复杂度、线密度和色块面积上限。

## 早期美式电视动画与近期日本动漫场景的差异

| 维度 | 必须采用：早期美式二维电视动画 | 必须排除：近期日本动漫场景倾向 |
| --- | --- | --- |
| 叙事重心 | 人物脸部、姿态和单一动作主导 | 背景奇观、环境展示主导 |
| 空间 | 平视、侧向或轻微三分之四；浅空间；舞台式横向展开；弱透视、少消失线 | 复杂多点透视、广角畸变、低机位仰角、纵深漫游 |
| 场景结构 | 一个主活动区，通常至多三层，大面积安静色块 | 高密度建筑、街景和精细室内陈设铺满画面 |
| 线条层级 | 可动层深且较闭合；固定背景少线、浅线、开放边缘 | 背景每件物体都粗黑闭合并精细描绘 |
| 材质 | 靠大形与固有色识别 | 砖缝、木纹、瓦片、窗格、反射和纹理展示 |
| 光色 | 中等饱和与对比；0–1 层扁平阴影 | 逆光轮廓、光晕、景深、空气透视、体积光、戏剧化黄昏 |
| 自然 | 少量不对称色团、平面云、剪影远景 | 写实云层、花瓣、天气粒子、繁密枝叶和草线 |
| 镜头功能 | 固定绘景服务表演 | 镜头运动展示大量背景信息 |

正向不得使用 `anime style` 这类泛词。只使用明确媒介描述，避免把模型引向近期日漫。

## 内容—风格边界

内容层包括世界、时代、地域、文化、类型、剧情、身份、服装、建筑、物品、生物、技术、文字和构图，由用户或原创决定。美学层只负责几何、线条、平涂、综合色、复杂度、层级、植物概括和有限动画。

任意时代、地区和世界观均可使用。古代宫殿、未来飞船、奇幻城市等只改变内容名词，不改变低复杂度表达：用少量代表形、分组剪影和大综合色块说明主题，不逐件展开。替换掉参考图具体人物、地点和物件后，规则仍须成立。

## 核心不变量

- 用户事实与 `preserve` > 用户内容参考 > 用户构图参考 > 内置美学参考。
- 有原创人物真实附加 01；纯场景至少附加一张 02–05；人物场景同时附加 01 和至少一张 02–05。
- 场景资产职责必须包含“复杂度上限 + 线密度上限 + 色块面积关系”，不能仅作综合色灵感。
- 人物是主导视觉；环境只提供动作所需信息。背景对比、饱和度和线密度低于人物与主要道具。
- 单镜头一个主活动区；大型空间通常不超过三层；必须保留大面积安静背景。
- 背景信息不足是合格的主动简化。复杂世界也必须分组概括，不能通过增加小物和纹理表现复杂。
- 默认原创；若用户提供或明确指定既有角色设定，只继承用户要求保留的身份与外形锚点，不从参考资产补入其他内容。

## 角色几何硬锁

- 默认约 2.5 头身，头部视觉高度约占全身 40%；肩宽明显小于头宽；躯干和四肢短而概括。
- 头近圆或略纵长，严禁横向压扁。
- 小而稳定的点眼；醒目圆鼻或 C 形鼻，视觉中心与眼线齐平或略高。
- 嘴为单根宽大弧线，横跨可见下半脸大部分宽度；脸内留白多。
- 逐角色预锁 `head_shape / nose_shape / eye_spacing / mouth_width_ratio`。转面、表情、跨图与多镜头不得切换。
- 群像共享几何语法，但每人至少以三个身份锚点区分；不得同脸。

## 场景复杂度预算

以下是默认视觉预算，可因用户明确剧情需求小幅调整，但不能取消概括原则：

- **主活动区**：每个镜头只有一个。次要事件必须并入该区或省略，不创建多处竞争焦点。
- **空间层级**：大型空间通常不超过三层：前景遮挡层／主要活动层／简化背景层。不是每幅都必须三层，严禁为了纵深增加额外层。
- **主视觉物件**：约 3–7 个，包括角色直接使用或剧情识别所必需的大物件。
- **次要小物**：尽量 0–5 个；不影响动作、地点识别或剧情因果则删除。
- **同类重复物**：只画 2–4 个代表，其余合并为综合色块或剪影；禁止铺满。
- **安静区域**：保留大面积空墙、地面、天空或单综合色背景。大色块应在缩略图中主导画面。
- **内部线**：主要物件通常只留 2–3 条识别线；固定背景更少。不得大量描绘砖缝、木纹、瓦片、叶片、草叶、餐具、书脊、按钮或窗格。
- **复杂场景**：转译为“主题丰富但表现概括”。将宫殿、城市、飞船、市场等按少数建筑群、设备组、摊位组或人群块组织；不得逐件描绘，也不得均匀提高细节。

## 空间、构图与镜头

- 默认平视、侧向或轻微三分之四视角，浅空间、舞台式横向展开、弱透视、少消失线。
- 固定背景像表演舞台的绘景，先提供人物站立、行走、拿取和互动所需边界；不展示完整世界结构。
- 用户明确指定俯视、仰视、广角或其他视角时可以服从，但必须减少透视线、空间层和物件数量，保持背景概括。
- 不用低机位英雄仰角、广角拉伸或复杂纵深来提升戏剧性。
- 缩小后视觉顺序必须是：人物／动作 → 主要道具 → 2–4 个大综合色块；不得先读到背景纹理或光效。

## 线条、材质与渲染

- 角色与可动物件：更清楚、更深色、基本封闭的赛璐珞轮廓；轻微线宽变化、柔和偏摆与极少自然收笔缺口。
- 固定背景：线更少、更浅、更不闭合；很多边缘只由相邻大综合色块形成。背景不得与角色同样粗黑、闭合、精细。
- 色面平整，只允许低频、轻微涂色不均；不用高频噪点、厚纸纹、厚涂、水彩晕染或光滑 3D。
- 背景不靠材质细节展示完成度；不铺砖缝、木纹、瓦片、叶片、草叶、餐具、书脊、按钮、窗格、电线或招牌。

## 色彩关系与光线

- 使用中等饱和、中等对比、大块固有色；背景综合色比角色与关键道具更安静。
- 阴影通常为 0–1 层扁平综合色，只在动作和形体识别必需时保留。
- 无复杂局部光源、动态光斑、写实反射、镜面高光、空气透视、景深虚化、体积光或镜头光晕。
- 无日漫式黄昏辉光和电影级色彩脚本。参考 05 的晚霞只允许地平线附近或画面下部一条克制综合色带；天空其余部分保持大而简单，不能演变成戏剧化云海。
- 不加统一灰黄怀旧滤镜，也不使用渐变塑形。

## 植物与自然

- 每棵树由少量不对称综合色团概括，树冠边缘开放或互相遮挡；远树以单一或少数组合色剪影出现。
- 草地是连续大色块，只用极少短线提示转折，不铺密集草线。
- 云朵少量、平面、边缘简单；天空保留大面积空白或单综合色。
- 远景树与建筑均以综合色剪影出现，不逐窗、逐枝、逐叶描绘。
- 禁止花瓣、漂浮粒子、繁密枝叶、写实云层、复杂天气粒子和精细自然背景。

## 动作、动画与视频

- 每镜头只保留一个主要动作：准备—主要动作—结果—短暂停顿或衔接。
- 环境响应只留与动作因果直接相关的少量变化，如一个道具轻移、一小块尘土或一扇门开合；默认不使用粒子群和复杂光线变化。
- 镜头以固定或克制移动服务动作可读性；禁止通过推拉摇移、航拍或长距离漫游展示大量背景信息。
- 固定背景不呼吸、不形变；角色关键姿态优先于过度顺滑补帧。
- 静态资产不能证明声音规律；台词、音乐和拟音按用户需要创作，不作为固定风格事实。

## 单独负面模块：近期日本动漫场景漂移

出现以下任一倾向即视为风格偏移，必须删减并重做：

- 高密度建筑或街景、复杂多点透视、广角畸变、低机位仰角。
- 精细室内陈设、无数电线、招牌、窗格、砖缝、瓦片、书脊、餐具或按钮。
- 写实云层、樱花花瓣、漂浮尘埃、雨雪粒子或复杂天气层。
- 逆光轮廓光、镜头光晕、空气透视、景深虚化、体积光、动态光斑。
- 玻璃／金属写实高光、精致食物特写、写实反射和复杂材质纹理。
- 日漫式黄昏辉光、戏剧化天空、电影级色彩脚本。
- 背景大量深色描边、每件物体闭合、背景与角色同等线重和细节。
- 为“丰富、精致、细腻、沉浸式、电影感、氛围感、充满生活细节”而增加无剧情功能的小物或光效。

## 质量检查

- **缩略图测试**：缩小后主要读到人物、动作与 2–4 个大色块。先看到建筑纹理、密集物件或光影特效则失败。
- **删减测试**：试删 30%–50% 背景小物；剧情不受影响则这些小物本来就不该出现。
- **日漫漂移检查**：对照独立负面模块逐项检查；命中任一项即简化重做。
- **人物主导检查**：背景对比、饱和度或线密度不能超过脸部轮廓、动作姿态和主要道具。
- **附件检查**：场景任务真实附加至少一张场景资产并标注三项上限职责；人物场景同时附加 01；调用后核验载荷。
